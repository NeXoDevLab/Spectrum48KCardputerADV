# Imágenes

`basic-v03.png`: captura USB del BASIC del Spectrum en el Cardputer ADV.
Las imágenes de carga y pantalla final son fotogramas RGB565 del flujo USB de los juegos
indicados en el nombre, decodificados sin recrear gráficos ni textos.

`cardputer-adv-template.png`: fotografía de M5Stack, reutilizada de la galería
Amstrad con la referencia facilitada por el usuario. Solo actúa como marco de
los vídeos; la pantalla real emulada se coloca a 240×135.

Véase `../media/README.md` y los JSON de cada vídeo para su procedencia.
